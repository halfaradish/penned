# 一木记账信息架构分析（基于 6 张截图，2026-10-05）

> 样本：`docs/local/一木记账部分界面/`（首页、日历、资产、统计、我的、统计长图；私密截图不入库）。
> 交叉验证：我的页"已记录 751 条账单" = 导出文件 751 行 ✓

## 一、导航骨架

**底部 5 Tab**：首页（明细）· 日历 · 资产 · 统计 · 我的
**全局元素**：右下悬浮球（语音/文字/截图快捷记账，权益表"悬浮球记账"）；各页右上 ⋮ 更多菜单。

## 二、分页结构

### 1. 首页（明细）
- 顶栏：账本切换（左上）· 搜索 · ⋮
- 运营横幅位（可关闭）
- 月汇总卡：本月收入 / 本月结余 / 剩余预算（未设置时"点击设置"）/ 本月支出（大字）
- 主按钮：「添加一条新记账」
- 流水列表：按日分组，日头 = `10月4日 昨天 周日` + 日收/日支；条目 = 分类图标 + `一级-二级` 分类名 + 备注 + 金额（支出红、收入绿）。**条目不显示账户名**（与导出账户全空互证：该数据未启用账户）
- 日历/首页均有悬浮球

### 2. 日历
- 头部：年月 + 月收/支/余 + 「今」回到今天 + 快速记 + ⋮
- 月历：农历 + 节气/节日；有账日的格子下标注 `-16 / +0`（支/收）
- 点选日期 → 下方显示当日账单列表（空态插画）

### 3. 资产
- 净资产卡：净资产（大字 + 眼睛隐藏）· 总资产 · 负资产 · ⋮（**"按账本设置不同资产"→ 账户归属账本**）
- 三入口卡：**报销**（可报/已报）· **债务**（应付/应收）· **理财**（总额/盈亏）
- 账户列表（分组展示，空态引导 + 右下 ＋ 新增）

### 4. 统计
- 视图切换：日常 / 月统计 / 年统计 / 自定义（会员"自定义统计"）
- 维度快切：2026 + 本月/上月/8月/7月…（横滑）
- 模块卡片流（共 10 个，即会员"统计模块设置"的配置项，也是图表需求清单）：
  1. 月汇总卡（支出/收入/结余，可展开）
  2. 收支统计：按日柱状图，支出/收入/结余切换，右上角编辑（自定义）
  3. 资产走势：折线面积图
  4. 收支对比：**桑基图**（收入来源→支出流向，一级分类/全部切换）
  5. 支出占比：环形图（中心总额；全部分类/显示金额开关；支出/收入切换）
  6. 支出数据：分类排行条形列表（笔数/占比/金额/**上月同期环比**）
  7. 报表统计：表格（日期/收入/支出/结余，按日倒序）
  8. 标签占比：环形图
  9. 标签数据：排行
  10. 本月总结：**用户手写文字总结**（LLM 增强点）
- 图表选型映射：柱状/折线面积/环形/条形排行 → Vico 或自绘 Canvas；**桑基图 → 需自绘**（Vico 无此类型）

### 5. 我的
- 用户卡：头像/昵称/坚持记账天数/账单总数
- 会员推广卡（penned 中替换为更新检查/关于）
- 功能宫格 8 入口：**自动记账** · **周期记账** · **愿望清单** · **分类关键词** · 账本管理 · 标签管理 · 分类管理 · 更多设置
- 数据管理组：**云同步**（未开启时红字"数据仅存本地"）· 数据备份 · 导入导出 · **账单图片**（附件中心）
- **「分类关键词」是一级入口** = 关键词→分类规则表，即自动分类/智能标签的用户可编辑引擎（对应我们 `CategoryKeywordRule`，M4 的规则引擎 UI 直接对标此页）

### 6. 记一笔页（2026-10-05 补充截图，详见 `docs/记一笔界面分析与重设计.md`）
顶栏 = 返回箭头 + 类型 Tab（**支出/收入/转账/债务**四入口，债务为快速记债）+ 编辑（分类管理）；分类区 = 白卡片内 5 列图标网格（线条图标圆底，选中青绿实心），一级分类行内展开子分类条带（含"+ 新增"）；底部信息条 = 标签 + 备注 + 右侧实时金额，第二行为 chips（今天/无账户/不报销/附件/优惠）；键盘 4×4 含**计算器表达式**（+−×÷）与**再记**（保存并继续）/取消键。

## 三、对数据模型的补充（截图新信息）

1. **账户归属账本**（"按账本设置不同资产"）→ `Account.bookId`；流水外键可空维持不变
2. **报销是状态机**：资产页汇总"可报/已报" → 流水的报销标记有待报/已报状态，汇总可重算（`reimburseState` + 报销账户/金额）
3. **债务分方向**：应付/应收两个汇总 → 债务实体带 direction 字段
4. **理财有盈亏** → 理财账户需要净值/市值快照（`AssetSnapshot`），盈亏 = 现值 - 成本
5. **净资产 = 总资产 - 负资产**，纯重算值，不落库
6. **分类关键词规则表**（`CategoryKeywordRule`: 关键词 → 目标分类，优先级/启用位）——"智能标签/自动分类"的免费实现底座
7. 本月总结 = 按月的用户文本（`MonthlyNote`），LLM 可代写

## 四、数据模型信息充分性结论

**足够，schema v1 可定稿开工。** 导出文件给了字段级证据（退款/优惠/报销三字段/多币种/地址/创建者/附件≤5/分类树/分钟精度/分存储），截图补齐了实体关系（账户归属账本、报销状态、债务方向、理财快照、关键词规则、月度总结）。

2. "优惠"字段取值格式

4. 预算的周期类型枚举（月/年/自定义，按通行设计）
