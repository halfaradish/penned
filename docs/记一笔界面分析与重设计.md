# 记一笔界面分析与重设计方案（M0.5 提案）

> **已过时（2026-10-06）**：本文是 M0.5 的重设计规格，其"视觉基调 / 布局 / 键盘"部分已被
> `docs/界面重构方案.md`（D024）整体取代——记一笔页现为：分段胶囊类型切换 + 分类宫格（子分类 chip 流展开）
> + 金额 hero 信息条 + 五列计算器键盘 + 右上「管理分类」入口。本文保留为**当时对标一木的分析记录**。

> 样本：`docs/local/一木记账部分界面/添加一条新记账/`（3 张：主界面、新增分类-线条风格、新增分类-多彩风格）。
> 背景：penned M0 记账页被评"丑、无返回"。本文解剖一木原版，给出差距与重设计规格。

## 一、一木"记一笔"结构解剖

### 1. 顶部：导航 + 类型 + 编辑
- 左上 `<` 返回箭头；右上"**编辑**"（直接进分类管理）
- 类型 Tab 一行四个：**支出**（选中=青绿胶囊）/ 收入 / 转账 / **债务**
- 新信息：**"债务"是记一笔的一级入口**（快速记债），转账也在一级入口

### 2. 分类区（白卡片，页面主体）
- **每行 5 个**，图标主导：浅灰圆底 + 黑色线条图标，分类名在图标下方
- 选中态：青绿实心圆 + 白图标 + 青绿文字
- 有子分类的一级右上角带青绿"···"小徽标
- **点选一级 → 其子分类以灰色圆角条带在原地展开**（行内展开，不跳页），条带尾部含"+ 新增"
- 一级分类自动换行铺满（其他/购物/餐饮/交通/娱乐 一行，居家/教育/人情/医疗 一行）
- 图标有**线条/多彩两套风格**可选（新增分类页里切换）

### 3. 底部信息条（白卡片，两行）
- 第一行：🏷 标签 | "添加备注"输入 | 右侧**实时金额 0.00**（红色大数字）
- 第二行 chips：📅 今天 | **无账户** | **不报销** | 📎 附件 | ¥ 优惠
- 印证：账户可空（D005）、报销是流水状态（D008）、标签为流水属性

### 4. 键盘（4 列 × 4 行）
```
[ 1 ][ 2 ][ 3 ][ ⌫ ]
[ 4 ][ 5 ][ 6 ][ + − ]
[ 7 ][ 8 ][ 9 ][ × ÷ ]
[ 再记][ 0 ][ . ][ 取消]
```
- **计算器表达式输入**（+−×÷，金额可算："菜 12 + 肉 8"）
- **再记** = 保存并清空继续（连续记账）；取消 = 关闭页面
- ⌫ 在右上，退格高频位

### 5. 新增分类（全屏弹层）
- X / ✓ 顶栏；字段：名称、图标（可搜索/自定义）、夜间模式图标、"仅在当前账本显示"开关
- 图标选择器：风格切换 + 搜索 + 左侧分组栏（收入/餐饮/宠物/出差/服饰/公司/家庭）+ 图标网格

## 二、与 penned M0 的差距

| 维度 | 一木 | penned M0 | 定性 |
| --- | --- | --- | --- |
| 返回 | ← 箭头 + 键盘"取消"键 | **无任何返回途径** | P0 功能缺失 |
| 类型 Tab | 支出/收入/转账/债务 | 支出/收入 | 转账/债务按计划 M1 |
| 分类视觉 | 线条图标 + 圆底，图标主导 | 色块 + 首字，廉价感 | **观感核心差距** |
| 分类布局 | 每行 5、一级换行铺满、子分类行内展开、有"···"徽标 | 每行 4、全部平铺无层级 | 交互结构差距 |
| 宫格内新增 | 有"新增"格子 | 无 | 小缺失（M1 接分类管理） |
| 备注与金额 | 同一行：标签+备注+右对齐实时金额 | 金额独立大字块 + 独立备注框 | 布局差距 |
| 快捷 chips | 日期/账户/报销/附件/优惠 全部可点 | 只有静态日期文本 | M1 逐步补 |
| 键盘 | 再记/取消/计算器 | 00/C/保存 | 再记值得抄；计算器 M1 |
| 整体质感 | 浅灰底 + 白卡片分层 | 平铺无层次 | 视觉 |

## 三、重设计规格（M0.5，待批后实施）

**视觉基调**：浅灰底（surface 变体）+ 白卡片（16dp 圆角）+ 青绿主色 + 支出红/收入青绿金额。

1. **顶栏**：← 返回（修复 P0）| 类型 Tab 支出/收入（转账/债务 M1）| 右上"编辑"占位（M1 接分类管理）
2. **分类卡片**（weight(1f)，可滚动）：
   - 5 列网格：浅灰圆底 + **首字/图标** + 下方名称；选中 = 青绿实心 + 白字
   - 点选一级 → 行内展开灰色圆角条带显示其子分类 + 尾部"+ 新增"占位；点子分类直接选中该子分类
   - 图标策略：维持色块方案但改为**中性圆底**（浅灰底 + 深色首字，选中反色）——观感对齐且不违反 D011；自绘线条图标集列入 M6 提案
3. **信息条卡片**（键盘上方）：
   - 第一行：备注输入（无边框，占位"添加备注"）+ 右侧实时金额（红色等宽，0.00 起显）
   - 第二行 chips：**今天**（M1 可改日期）| **无账户**（M1 可选账户）；报销/附件/优惠 M1 后补，M0.5 不放假按钮
4. **键盘**（4×4）：
   ```
   [ 1 ][ 2 ][ 3 ][ ⌫ ]
   [ 4 ][ 5 ][ 6 ][ C ]
   [ 7 ][ 8 ][ 9 ][ 00 ]
   [ 再记][ 0 ][ . ][ ✓ 完成]
   ```
   - ✓ 完成 = 保存并返回（青绿高亮，金额/分类合法时可用）
   - 再记 = 保存并清空金额/备注（保留分类，连续记账）
   - 顶栏 ← 承担"取消/返回"；键盘不再放取消键（一木的取消键与其无返回箭头冗余设计相关，我们二选一即可）
   - 计算器表达式（+−×÷）列入 M1 提案
5. **同步动作**：截图基线重录（含新布局 Roborazzi 断言：返回按钮存在、子分类行内展开可见）

## 四、范围与节奏

- **M0.5（本提案）**：上述 1~4 全部 + 截图基线更新
- **M1**：转账/债务 Tab、账户/报销/附件/优惠 chips、宫格内新增分类、"编辑"入口、计算器键盘
