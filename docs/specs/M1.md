# 规格 M1：核心可用（冻结 2026-10-05）

来源：可行性方案里程碑表、信息架构分析、探索报告（docs/local/一木模拟机探索/探索报告.md）、决策 D020~D022。
分两批实施；本文件冻结总范围与验收标准，"第二批"开工前如有变更走 decisions。

## 第一批（本批实施）

### S1 Schema v2 迁移
- `transactions` 增列：`excludeFromStats`（默认 false）、`excludeFromBudget`（默认 false）、`source`（TEXT，默认 "MANUAL"）、`feeCents`（默认 0，转账手续费，D020~D022）
- 新表 `budgets`（id/bookId/categoryId 可空=总预算/amountCents/period/日期范围字段/sync 字段）——本批只建表，UI 第二批
- 新表 `import_batches`（id/bookId/fileName/importedAt/count/sync 字段）——本批只建表，第二批接导入器
- Room version 1→2，schema JSON 入库，Migration 测试（建 v1 库 → 迁移 → 断言新列/新表存在且旧数据保留）

### S2 计算器表达式（纯函数）
- `MoneyExpression`：支持 `+ - × ÷` 与小数，键盘实时显示表达式，按 `=` 求值；表达式待算时完成键位置显示 `=`
- 表驱动单测：四则、连续运算、除零保护、精度（分为单位结算）、非法输入

### S3 设置项 + 账本管理
- 引入 `datastore-preferences`（D023），存当前账本 id 等设置
- 首页左上账本名点击 → popover：账本列表 + 新增/管理
- 账本管理页：列表 + 新增/重命名/切换当前账本（删除=软删，M1 不做合并）
- 首页数据随当前账本过滤

### S4 资产 Tab（账户管理）
- 净资产卡：净资产/总资产/负资产（全部由 账户初始余额+流水 重算，D004）
- 账户列表按分组显示，余额 = 初始余额 + 收入 - 支出 ± 转账（重算）
- 添加账户：类型分组预设（资金账户：现金/借记卡；信贷账户：信用卡；投资理财；负债；自定义名称）+ 名称 + 初始余额
- 报销/债务/理财三卡位：本批静态汇总（报销可报/已报由流水重算；债务/理财占位）

### S5 记一笔 v2
- 类型 Tab：支出 / 收入 / **转账**（债务 M3）
- 支出/收入：chips 中"无账户"变为**账户选择 chip**（弹层选账户，可选"无账户"）
- 转账：转出/转入账户两个选择框 + 互换 + 手续费 chip（录入手续费金额）
- 键盘升级为计算器（S2），完成键三态语义
- 保存：转账写 `type=TRANSFER + targetAccountId + feeCents`；支出/收入带 `accountId` 与 `source`

### S6 账单详情 / 编辑 / 删除 / 批量删除
- 点流水行 → 账单详情页：全字段展示（含记录时间/记录方式）+ 编辑 / 删除 / 退款占位（M3）
- 编辑 = 复用记一笔页（预填）；删除 = 软删
- 首页长按行 → 批量模式：多选 + 批量删除（软删）
- 详情页含"不计入收支/不计入预算"开关（D020）
