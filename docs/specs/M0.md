# 规格 M0：地基（冻结 2026-10-05）

来源：`docs/可行性分析与技术方案.md` 里程碑表 + `docs/local/一木导出反分析.md` + `docs/信息架构分析.md`。

## 范围

1. **工程骨架**：Gradle + version catalog（版本冻结）+ 镜像仓库 + app 单模块
2. **Room schema v1**（M0/M1 所需 7 表，同步字段预留）：
   - `books`（账本）
   - `accounts`（账户：类型 CASH/DEBIT/CREDIT/INVEST/DEBT，bookId 必填，余额=initial+重算）
   - `categories`（分类树：parentId 自引用，CategoryType 收/支两域，二级可空）
   - `transactions`（流水：EXPENSE/INCOME/TRANSFER 多态，Long 分，分钟精度时间，refund/discount/reimburse 字段预留，accountId 可空）
   - `tags`（两级标签）、`transaction_tags`（多对多）、`attachments`（附件，≤5 由逻辑保证）
   - 同步字段全表预留：uuid 主键、createdAt/updatedAt、deleted、deviceId
   - schema export 开启（app/schemas/ 入库）
3. **种子数据**：首启种入"日常账本"+ 默认分类树（支出一级 8 组 + 观察到的二级；收入域 5 个一级）
4. **UI 骨架**：底部 5 Tab（首页/日历/资产/统计/我的，后四者为占位页标注实现里程碑）+ 首页流水列表（日分组、日收支、月汇总头）+ 记账页（支出/收入切换、金额键盘含 00/⌫/C、分类宫格、备注、保存入 DB）
5. **测试基线**：Money 解析/格式化表驱动单测；日分组纯函数单测；DAO Robolectric 测试（种子/插入/软删/汇总）；Roborazzi 截图测试跑通出 PNG
