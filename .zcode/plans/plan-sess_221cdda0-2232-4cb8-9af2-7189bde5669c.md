## 目标

预算与月汇总拆成**两张卡**；预算卡用月汇总同款三列布局（标签一行 + 数值一行），只多一条进度条。

```
┌──────────────────────────────────────┐
│    支出       收入       结余        │   ← 月汇总卡（不变）
│   22.00      0.00     -22.00         │
└──────────────────────────────────────┘
┌──────────────────────────────────────┐
│    预算       已用       剩余        │   ← 预算卡（三列同款布局）
│  3000.00     22.00     2978.00       │      超支时"剩余"红字负数
│ ▓░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ │   ← 只多这一条 4dp 进度条
└──────────────────────────────────────┘
```

## 改动

### `app/src/main/java/dev/penned/app/ui/home/HomeScreen.kt`

1. LazyColumn 头部 item 从两个变三个：`month-card` → **新增 `budget-card`**（`BUDGET_CARD_KEY`）→ `add-button`；每张卡垂直外边距 6dp（卡间距 12dp）。FAB 显隐逻辑不动（仍按 `add-button` 的 key 判断）。
2. `HomeSummaryCard` 精简为只画月汇总（`totals` 单参数 + `modifier`），内部就是现有三列 `SummaryColumn`（支出/收入/结余）。
3. 新增 `HomeBudgetCard(budgetSummary, onOpenBudgets, modifier)`：
   - **有预算**：`Card(clickable → 预算管理)` + 三列 `SummaryColumn("预算" 3000.00 / "已用" 22.00 / "剩余" 2978.00)`，其中"剩余"正常用 primary 绿、超支用 expenseColor 红（`BudgetMath.state` 的 `remainingCents` 超支时本身为负）+ 下方 4dp `LinearProgressIndicator`（超支红）
   - **未设预算**：同一槽位渲染一张瘦卡，内容是可点的「设置本月预算，控制花销 →」（labelMedium / primary）
4. 删掉合并卡里"剩余预算 …"那行与右侧"预算 3000.00 · 已用 22.00"文案（信息已由三列表达）。
