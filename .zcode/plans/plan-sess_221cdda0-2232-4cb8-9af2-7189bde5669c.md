## 目标

首页固定区只留标题栏（账本名 + 搜索）；月汇总与预算**合并成一张卡**并入可滚动列表；「添加一条新记账」按钮随内容滚走；右下角绿色 FAB 在按钮滚出视野后接管其功能。

## 改动

### 1. `app/src/main/java/dev/penned/app/ui/home/HomeScreen.kt`（主要改动）

**合并卡**：新增私有 `HomeSummaryCard(totals, budgetSummary, onOpenBudgets)`，替换掉现有 `SummaryCell` + `BudgetSummaryRow` 两块：

```
┌──────────────────────────────────────┐
│ 支出 22.00   收入 0.00   结余 -22.00 │  labelSmall + titleSmall，内边距 12/10dp
│ 剩余预算 2978.00   预算 3000.00 已用 │  ← 这一行可点 → 预算管理
│ ▓▓░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ │  ← 4dp 进度条（超支红）
└──────────────────────────────────────┘
```
- 无预算时第二行改为可点的「设置本月预算，控制花销 →」（无进度条）
- 只有第二行可点（点"支出"跳预算管理会很意外）；合并卡总高约 100dp，替代原来两块约 200dp

**布局骨架**：`Column { 标题栏 Row（固定，不动）; Box(Modifier.weight(1f)) { LazyColumn(state, testTag("home-list")) …; FAB } }`，其中 LazyColumn 的 item 顺序：
1. `item(key = "month-card")` → 合并卡（选择模式不渲染）
2. `item(key = "add-button")` → 「添加一条新记账」（垂直 padding 16→8dp）
3. `item(key = "empty")` → 空态提示（文案不变，从"整屏居中"改成列表项）或各日分组

**FAB**：`FloatingActionButton(onClick = onAdd, containerColor = primary, contentColor = onPrimary, Modifier.align(BottomEnd).padding(16.dp).testTag("home-fab")) { Text("+", titleLarge) }`，外层 `AnimatedVisibility(fadeIn/fadeOut)`（若 Robolectric 下不稳定则退回 `if (showFab)`）。
- 位置：HomeContent 的可用区域已排除底部导航栏（PennedApp 在 NavHost 层消费 padding），所以 FAB 落在导航栏正上方
- 绿色用 `MaterialTheme.colorScheme.primary`（#2F9E8F，与"完成"键同色；资产页 FAB 用的 primaryContainer 是浅色，这里按"绿色圆按钮"要求显式指定 primary）

**显隐逻辑**：`rememberLazyListState()` +
```kotlin
val addButtonVisible by remember { derivedStateOf { listState.layoutInfo.visibleItemsInfo.any { it.key == "add-button" } } }
val showFab = !selectionMode && listState.layoutInfo.totalItemsCount > 0 && !addButtonVisible
```
`totalItemsCount > 0` 是防首帧闪现；选择模式下卡片/按钮本就不渲染，FAB 一并隐藏。

**预览**：`HomeDataPreview` 补传 `budgetSummary`，IDE 预览同时覆盖"有预算"形态。
