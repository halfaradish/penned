## 界面整体重构方案（M1 后置重构，走 board 提案 + D024）

按你选定的方向：**精致化现有青绿体系**、四种交互范式全上、首页记一笔入口保持现状、全量 15 屏一次做完。下面先诊断，再给规范与切片。

---

### 一、诊断（已核对代码与实机截图）

**视觉根因两条：**
1. **分类色是哈希彩虹**。`categoryColor()`（`ui/home/HomeScreen.kt:411`）用黄金角把名字哈希成任意色相——首页头像出现蓝/紫/洋红同屏，统计页环形图与占比条是紫/洋红/橙，与青绿品牌色互相打架。这是"显旧"的第一来源。
2. **没有设计层**。`ui/theme/Type.kt:5` 是 `Typography()` 全默认；无 `Shapes.kt`、无间距/圆角常量（各文件硬编码 `RoundedCornerShape(16/12/10/8/14.dp)`）；卡片是无边无界的灰块，与背景仅差 ~2% 亮度；M3 `error` 槽位是默认紫（锁屏键盘可见）；`res/values/themes.xml` 只有浅色，深色下冷启动闪白。

**布局缺陷根因（已定位到行）**：首页搜索页顶部那块"无内容无交互"的空白是**状态栏 inset 被算了两遍**。`ui/nav/PennedApp.kt:58` 的外层 `Scaffold` 无 topBar → 默认把状态栏 inset 作为 `padding` 给到 `NavHost`（`:83`），而普通 `padding` **不会**标记 inset 已消费；搜索页自己的 `Scaffold`+`TopAppBar`（`SearchScreen.kt:122-127`）又按 `TopAppBarDefaults.windowInsets` 加了一遍状态栏高度 → 真机上约 2× 状态栏（48~100dp）的死带。同型问题在 9 个下钻页 + `MineScreen`/`AssetsScreen` 内部 Scaffold 上；底部同理（内层 Scaffold 无 bottomBar 再加一遍导航栏 inset）。Roborazzi 截图是零 inset 环境，所以一直没暴露。

**交互陈旧点**：全部二次确认走 `AlertDialog`（8 处）；列表零手势；页面切换无转场（NavHost 默认硬切）；返回键是文字 `"‹ 返回"`、次级箭头是 `"›"`、FAB 是文本 `"+"`、勾选是 `"✓"`（只有记一笔用了真矢量 `PennedIcons.Back`）；删除不可撤销；`记一笔`顶栏「编辑」是 disabled 死 UI（board 待办）。

### 二、设计规范（写进 `docs/界面重构方案.md`，token 落进代码）

**原则**：① 金额是主角——每屏最大的字是金额，数字一律 `tnum` 等宽、右对齐成列；② 一张表面语言——白卡 + 1dp 发丝线 + 16dp 圆角，全局不用阴影，深色靠表面提亮；③ 颜色只表达信息——界面唯一饱和色是支出红/收入绿，分类色只出现在头像/图表/占比条；④ 位置感一致——Tab 页用可滚走的页头（无固定 app bar），下钻页用紧凑顶栏（真返回箭头 + 标题 + 动作）；⑤ 动效回答动作——每种动效对应一个用户动作，不做装饰动画，系统"动画时长缩放=0"时全关。

**配色（浅色 / 深色）**

| 语义 token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| primary | `#2F9E8F`（不变） | `#6FD3C1` | 品牌填充：主按钮、FAB、选中胶囊 |
| primaryInk | `#16756A` | `#6FD3C1` | 品牌**文字**（白底 5.5:1；现用的 `#2F9E8F` 只有 3.3:1，不合格） |
| primaryContainer | `#D8F0EA` | `#0F5045` | 选中底、标签底 |
| background / surface | `#F2F5F4` / `#FFFFFF` | `#0E1211` / `#171C1B` | 页底 / 卡片（拉开层次，现在几乎同色） |
| surfaceContainer / High | `#EAF0EE` / `#E2E9E6` | `#202725` / `#272E2C` | 输入框、键盘键、chips、按压态 |
| outlineVariant / outline | `#E3E9E6` / `#C4CEC9` | `#2A3230` / `#47514E` | 1dp 发丝线 / 强边界 |
| onSurface / onSurfaceVariant | `#101715` / `#5D6866`(5.8:1) | `#E3E9E7` / `#9BA6A3` | 主文字（墨）/ 次要文字 |
| expense / income | `#C0453C`(5.1:1) / `#16756A` | `#F0908A` / `#6FD3C1` | 支出朱砂 / 收入青绿 |
| error | `#B3261E` | `#F2B8B5` | 删除、错误（顶掉 M3 默认紫） |

**分类颜料盘（8 色，同彩度同明度，取代哈希彩虹）**：朱砂 `#A8433A`、赭石 `#97602F`、藤黄 `#866C1F`、石绿 `#2F7A50`、石青 `#2F6A92`、靛青 `#47578F`、紫檀 `#7C4A66`、墨灰 `#586360`（深色各给一档提亮变体）。头像渲染 = 颜料 14% 透明底 + 颜料墨色首字（深色 20% 底 + 提亮字），对比度恒达标，且统计页环形图/占比条用**同一套颜料**——首页与统计页从此是一套色。分配仍按名字稳定哈希落 8 个槽位（保持"同名同色"），转账固定墨灰、未分类用中性。

**字阶**（系统字族，不引字体文件；量级不谈字体、谈层级 + 等宽数字）：displaySmall 32/38/600/-0.5（详情金额、实时金额、净资产）、headlineSmall 24/30/600（页头大标题）、titleLarge 20/26/600（顶栏标题）、titleMedium 16/22/600（行标题/卡标题）、titleSmall 14/20/600（日头/分组）、bodyLarge 15/22、bodyMedium 14/20、bodySmall 13/18、labelLarge 14/18/600（按钮）、labelMedium 12/16/500（元信息）、labelSmall 11/14/500/0.3（列标签）；所有数字样式带 `FontFeatureSettings("tnum")`。

**形状/间距**：圆角 8/12/16/20/28（extraSmall→extraLarge，卡片 16、输入 12、键 12、胶囊全圆）；间距 4/8/12/16/20/24（屏边距 16、卡内 16、卡间 12、分组间 24）。

### 三、共用组件库（新包 `ui/components/`，替换 15 处重复实现）

`PennedTopBar`（真返回箭头 + 标题 + 动作槽，一键替换 9 处 `"‹ 返回"`）· `PennedCard`/`SectionCard`/`SectionLabel` · `CategoryAvatar` · `MoneyText` · `DayHeaderRow`（首页/搜索共用）· `EmptyState`（统一 5 处空态）· `PennedChip`（统一 SelectableChip/StaticChip/FilterChip 三套）· `PennedDialog`/`ConfirmDialog`（统一 8 处弹窗）· `PennedSheet`（ModalBottomSheet 封装）· `PennedButton`（primary/tonal/destructive）· `PennedSegmentedTabs` · `UndoSnackbar`。

`ui/icons/PennedIcons.kt` 按现有手写填充路径风格补 ~16 个：Search、Plus、ChevronRight/Left、Close、Check、Trash、Edit、Calendar、Wallet、Tag、Lock、Info、Database、Transfer、MoreVert。清掉全部文字字形图标（`"‹"` `"›"` `"+"` `"✓"` `"⇅"`）。仍不引 material-icons-extended（D011）。

**无新依赖**：`ModalBottomSheet`/`SwipeToDismissBox`/`SegmentedButton`/`FlowRow`/`animateItem`/`stickyHeader`/`LocalHapticFeedback` 在已冻结的 material3 1.4.0 + foundation 1.9.5 里都有。

### 四、布局与 insets 修复

外层 `Scaffold` 的 `contentWindowInsets` 归零策略改为**在 `NavHost` 上 `Modifier.padding(padding).consumeWindowInsets(padding)`**——Tab 页继续吃外层 top inset（正确），内层 Scaffold/TopAppBar 因 inset 已消费不再重复加 → 搜索页死带消失，9 个下钻页顶部与底部同步修好。另加 `values-night/themes.xml` 消除深色冷启动白闪。此修复只能真机验证（Robolectric inset 恒 0），列入模拟机清单。

---

### 五、交互范式（你勾选的 4 项）

1. **底部抽屉代替弹窗**：账户选择、预算分类选择、更多操作改 `ModalBottomSheet`；纯文本输入（金额/命名）仍留居中弹窗。**先做 Robolectric 可行性 spike**（本仓有"弹窗内文本输入不 idle"前科），不行就退化并记录。
2. **行左滑删除 + 撤销**：`SwipeToDismissBox` 左滑软删 → 底部 Snackbar「撤销」；需补 `TransactionDao` 反软删方法与 VM 快照回滚。长按多选保留。
3. **转场与列表动效**：下钻页共享轴滑动淡入、Tab 切换淡入淡出、列表增删 `animateItem()`、子分类条带 `AnimatedVisibility`、抽屉默认动效；读系统动画缩放，为 0 时全部关闭。
4. **触感反馈**：键盘按键、长按进多选、左滑越过删除阈值各一次轻触感。

### 六、逐屏改造

- **首页**：页头（账本名 + 下拉指示 + 搜索图标按钮，替文字"搜索"）；月汇总/预算卡精修（列标签 11sp 弱化、数值等宽、支出朱砂/收入青绿/结余墨色）；**日头吸顶**；行重做（颜料头像、备注截断、金额成列）；空态换成统一 `EmptyState`；大按钮与 FAB 行为不动，只统一圆角/色/图标。
- **搜索**：顶栏换真返回箭头；输入框改带搜索图标 + 清除 ×的填充框；**进页自动聚焦并弹键盘**、列表加 `imePadding`（现在键盘会盖住结果）；未输入态的居中提示改为紧贴输入框的左对齐说明（消灭中段大片空白）；结果行复用新版行样式。
- **记一笔**：分段胶囊（支出/收入/转账）精修；宫格单元格 48dp 圆 + 名称 11sp，有子分类的小圆点移入圆内右下；**子分类条带改为 FlowRow chip 流 + 展开动画**；信息条金额上 `displaySmall` 等宽、chips 加图标；键盘键改白底 12dp 圆角 + 按压态 + 触感；**接通顶栏「编辑」→ 分类管理**（消掉 board 待办里的死 UI）。
- **统计**：环形图与排行条改用颜料盘（修掉紫/洋红/橙）；环 150→132dp、描边 26→18dp、圆角端点；中心显示合计；月份切换用真图标按钮；排行行 = 颜料头像 + 名称 + 等宽金额 + 自家颜料占比条。

- **详情**：顶栏返回 + 编辑动作；金额 hero + 分类头像；字段改分组卡（基本信息 / 开关 / 元信息）；退款标记改 pill badge；底部主按钮「编辑」+ 朱砂文字「删除」。

### 九、风险与边界

风险：① `ModalBottomSheet` 在 Robolectric 可能不 idle → 先 spike，失败则退化；② `stickyHeader` 与滚动断言；③ 15 屏全量会话很长 → 每片独立提交、board 记录停点，随时可停；④ 滑动删除与列表 key/分组的组合需实测。
边界（不做）：不动 DB schema、不加依赖、不改镜像配置；不重构 data/domain 层；不加规格外功能（组合筛选、退款编辑、预算算法都不碰）；不删任何现有入口（日历 Tab、搜索入口保留）；不抄一木资源。
