## 切片（每片 `./gradlew build` 全绿后独立提交）

1. **AD-1 千分位**：`Money.format(cents, grouped = true)` 默认输出 `3,500.00`；**输入框回填一律 `grouped = false`**（`AddViewModel` 编辑回填、`BudgetScreen` 初始金额、账户表单），否则光标/`parseToCents` 会吃逗号。`MoneyTest` 补表驱动用例（含 999.99 / 1,000.00 / -8,499.00 / 1,234,567.89 / 回填不带逗号 / 往返）
2. **AD-2 资产页**：整页 LazyColumn、浅青 hero + 眼睛、三张汇总卡、分组卡（小计 + 折叠）、金额语义色、圆形 FAB（60dp）；`PennedIcons` 补 `Eye`/`EyeOff`
3. **AD-3 类型抽屉 + 路由**：`AccountTypeSheet`（四组 × 5 列 + 自定义格）；FAB → 抽屉 → `account?editId=&group=&preset=`；表单页去掉 tab 与网格，改「所属分组」选择行
4. **AD-4 DB v4**：`accounts` 加 `remark TEXT`、`scopeAllBooks INTEGER NOT NULL DEFAULT 0`；Migration + `app/schemas/` JSON + 迁移测试（默认 0 = 保持现有"只在所属账本"行为，不改老数据语义）
5. **AD-5 生效账本语义**：`全部账本` = 该账户在每个账本可见、**余额按跨账本流水合并**（`AccountDao` 的可见性与余额子查询加 `a.scopeAllBooks = 1 OR t.bookId = a.bookId`）；`仅本账本` = 现状。表单两行接上（备注输入 + 生效账本二选一抽屉）；资产页行显示备注副标题；测试：跨账本可见性与余额合并、备注读写
6. **AD-6 文档 + 模拟机验证**：`界面重构方案.md` 第十二节改写为"按参考图重做"版、`decisions.md` **D027**（账户备注与生效账本口径、千分位）、看板（提案区记你这次的字段裁决 + 已完成条目）；模拟机走查（资产页折叠/眼睛、抽屉选类型、表单五行的读写、跨账本可见性用第二个账本实测）+ 截图归档

## 边界（不做）

- 一木的简称/卡号/账户图标/夜间图标/收益同步/计入总资产：新字段或新语义，留提案区
- 「生效账本」只做**二选一**（仅本账本 / 全部账本）；「指定 A、B 两个账本」要 join 表与更多语义，留提案区
- 品牌图标与插画不抄；账户头像仍是颜料首字
- 不加依赖、不动镜像、不改 M1 已冻结的其它屏（除千分位这一个全局格式化）

## 风险

- 千分位是全局观感变化（首页/统计/详情/预算都变），少量测试断言要跟着改；`parseToCents` 保持严格（拒逗号），靠回填 `grouped = false` 保证往返
- 跨账本余额口径会改 `AccountDao` 的 SQL：默认 `scopeAllBooks = 0`，老数据行为不变；实测用设备上的第二个账本（Bbook）验证
- 分组卡折叠 + 左滑删除 + `animateItem()` 组合沿用 UI-3 的既有解法（自建 swipe state）
