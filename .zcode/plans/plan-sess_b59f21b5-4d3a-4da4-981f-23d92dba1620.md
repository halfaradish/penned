# 生效账本改为「按账本多选」（AE-1~AE-4）

## 问题
上一版只做了二选一（仅本账本 / 全部账本），所以编辑账户页看不到你新建的 `test` 账本——现在改成列出账本、可勾选多个。

## 一、DB v5：账户-账本多对多（AE-1）

新表（沿用 `transaction_tags` 连接表的复合主键写法 + D003 的软删/时间戳）：

```
account_books(accountId, bookId, createdAt, updatedAt, deleted, deviceId)   PK(accountId, bookId)
```

- `MIGRATION_4_5` + schema `5.json` + 迁移测试（4→5 保数据、新表与索引存在）
- **所属账本**（`AccountEntity.bookId`）恒定可见，不进这张表

## 二、可见性与余额口径（AE-2）

- **可见性**：`scopeAllBooks = 1` **或** `bookId = 当前账本` **或** `account_books` 里有勾选且未删
- **余额**：把账本过滤整个去掉——账户余额恒等于「初始余额 + 它名下全部流水」。账户是同一个钱包，余额不该随可见性开关变化（这是 D027「全部账本按跨账本合并」的自然推广）；对未共享的账户行为与今天完全一致
- 删账本时级联软删 `account_books` 里指向它的行

## 三、表单：生效账本改多选（AE-3）

行摘要：勾了全部 → 「全部账本」；否则列账本名（「日常账本、test」）。点开抽屉：

```
生效账本
 [✓] 全部账本              ← 勾上 = 以后新建的账本也自动包含；下面列表收起
 ──────────────────────────
 [✓] 日常账本      所属     ← 所属账本恒定可见、置灰不可取消
 [ ] test
 [ ] Bbook
```

- **新建账户默认**：全部账本不勾、所属勾上、其余不勾 —— 与今天行为一致，不会让老账户"突然出现在别的账本"
- 勾任意一个具体账本会自动取消「全部账本」；保存时先软删旧 refs 再 upsert 勾选的（幂等，取消勾选即收窄可见范围）
- 点行仍是 `PickerRow`（右箭头 + 摘要值），多选在抽屉里完成

## 四、测试与文档（AE-4）

- `PennedDatabaseTest`：勾选账本后可见性扩大 / 取消后收窄 / 余额跨账本合并且不随可见性变化
- `MigrationTest` 4→5；`AccountEditScreenScreenshotTest` 加多选抽屉的截图与断言（含「所属」置灰项）
- 决策 **D028**（多选口径 + 余额口径推广，并给 D027 补注）；`界面重构方案.md` 第十二节改写这一段；看板把「指定 A、B 两个账本」从提案候选移到已做，补 AE 条目
- 模拟机实测：用你新建的 `test` 账本走一遍（只在自己建的测试账户上勾选/取消，验完删除测试账户，不动你的账本与流水）

## 不做（留提案区）

- 把账户**移出**所属账本（那等于迁移账户归属，是另一件事）
- 账本列表的排序/搜索（账本数量少，直接列出）

## 风险

- 余额 SQL 去掉账本过滤：对未共享账户行为不变（它们的流水本来只在本账本），用现有 + 新增测试双向覆盖
- 老数据迁移后：`scopeAllBooks = 0` 且无 refs = 与今天完全一致
